| Befehl                | Zweck                                 | Beispiel                             |
| --------------------- | ------------------------------------- | ------------------------------------ |
| `ip addr`             | Zeigt Netzwerkadapter und IP-Adressen | `ip addr`                            |
| `ip link`             | Zeigt Netzwerkinterfaces              | `ip link`                            |
| `ip route`            | Zeigt die Routing-Tabelle             | `ip route`                           |
| `ping`                | Testet die Erreichbarkeit eines Hosts | `ping google.com`                    |
| `hostname`            | Zeigt den Rechnernamen                | `hostname`                           |
| `hostname -I`         | Zeigt die lokalen IP-Adressen         | `hostname -I`                        |
| `ss`                  | Zeigt offene Netzwerkverbindungen     | `ss -tuln`                           |
| `curl`                | Ruft Webseiten oder APIs ab           | `curl https://example.com`           |
| `wget`                | Lädt Dateien herunter                 | `wget https://example.com/datei.zip` |
| `dig` oder `nslookup` | DNS-Abfragen                          | `dig example.com`                    |
